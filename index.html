How I approach a data problem

The same four steps in every project.

  1. UnderstandClarify the business question and the metrics that matter.
  2. CleanFix missing values, duplicates and data types before any analysis.
  3. AnalyseUse SQL, Pandas or Pivot Tables to find patterns and drivers.
  4. ExplainBuild the dashboard, then state the finding in plain words.
